# 28일 합성 데이터 내부 성능평가

평가일: 2026-08-15  
데이터: `data/seed_28days.json` 28일  
평가 성격: 합성 샘플 1개에 대한 내부 검증

## 평가 방법

단순 80/20 무작위 분할은 사용하지 않았다. 28일의 시간 순서를 유지하면서 최초 14일을 학습에 사용하고 다음 날을 평가한 뒤, 학습 구간을 하루씩 늘리는 walk-forward 검증을 적용했다.

```text
1~14일 학습 → 15일 평가
1~15일 학습 → 16일 평가
...
1~27일 학습 → 28일 평가
```

총 평가 일수는 14일이다. Ridge는 서비스 계산과 동일하게 `StandardScaler`와 `Ridge(alpha=3.0)`을 사용했다. 비교 기준은 과거 학습 구간 평균과 직전 피부 점수다.

## HabitPattern 결과

| 항목 | 결과 |
|---|---|
| 상위 3개 순서 | 수면 부족 → 야식 → 스트레스, 기대 순서 일치 |
| lag 일치 | 3/3 |
| 운동·화장품 impact | 모두 0.1 미만 |

이 결과는 합성 데이터에 의도적으로 심은 패턴을 복원하는지 확인한 것이다. 실제 사용자 데이터의 원인 규명 성능을 의미하지 않는다.

## Ridge 결과

| 모델 | MAE | RMSE |
|---|---:|---:|
| Ridge | 4.529 | 5.653 |
| 과거 평균 | 9.981 | 12.972 |
| 직전 점수 | 7.214 | 10.899 |

Ridge의 방향 정확도는 0.643(64.3%), 계산 범위에 실제 점수가 포함된 비율은 0.500(50.0%)이었다.

합성 데이터에서는 Ridge가 두 기준 모델보다 낮은 오차를 보였다. 다만 범위 포함률 50%는 현재 오차 기반 범위가 충분히 보수적이지 않음을 보여준다. 28일 합성 샘플 하나로 범위를 다시 조정하면 해당 데이터에 과적합될 수 있으므로, 이번 평가만으로 계산 방식을 변경하지 않는다.

## 해석 제한

- 실제 사용자 데이터의 일반화 성능이 아니다.
- `estimatedDifference`가 실제 습관 변화의 인과 효과와 일치하는지 검증한 결과가 아니다.
- 합성 데이터 하나에 대한 결과라 날짜 구성과 랜덤 시드에 민감할 수 있다.
- 별도 합성 데이터와 실제 파일럿 데이터가 확보되면 같은 평가를 다시 수행해야 한다.

실행 명령은 다음과 같다.

```powershell
python scripts/evaluate_model.py
```

기본 실행은 핵심 성능 요약만 출력한다. 날짜별 실제값·예측값을 포함한 전체 결과가 필요하면 다음과 같이 실행한다.

```powershell
python scripts/evaluate_model.py --details
```
